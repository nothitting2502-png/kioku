# データモデル

提案書 5.1「1つのセッションに対して、音声ファイル、文字起こしセグメント、メモ、タグ、作成日時を保持する」に対応します。

## 保存先

| 種類 | 保存先 | 理由 |
| --- | --- | --- |
| セッション（文字起こし・メモ・タグ） | IndexedDB `kioku` / `sessions` ストア（keyPath: `id`） | 件数が増えても検索できる |
| 音声 | IndexedDB `kioku` / `audio` ストア（keyPath: `sessionId`） | 容量が大きいので、必要なときだけ読む |
| 設定 | localStorage `kioku:settings` | 起動直後に同期的に読みたい |

## Session

```js
{
  id: 'ses_...',            // 一意なID
  title: '企画の打ち合わせ',
  purpose: '会話・打ち合わせ',
  participants: '自分、田中さん',
  tags: ['仕事', '企画'],
  status: 'draft' | 'recording' | 'done',
  createdAt: '2026-08-29T11:21:00.000Z',
  updatedAt: '...',
  startedAt: '...' | null,  // 最初に録音を開始した時刻
  durationMs: 73897,        // 一時停止を除いた収録時間
  segments: [Segment],
  notes: [Note],
  audio: { mimeType: 'audio/webm;codecs=opus', size: 152340 } | null
}
```

## Segment（文字起こしの1文）

```js
{
  id: 'seg_...',
  text: '来週までに見積もりを出す件を話した',
  startMs: 2000,            // セッション開始からの経過ミリ秒
  endMs: 4200 | null,
  createdAt: '...',
  updatedAt: '...',
  edited: false             // 文字入力で修正したか
}
```

**重要な設計判断（提案書 5.1）**: 認識の「途中結果」はセグメントとして保存しません。
確定した結果だけを Segment として履歴に残すため、表示は速いまま、あとからの編集がしやすくなります。
認識が途中で切れた場合は、残っていた途中結果を確定扱いで保存し、発言を取りこぼしません（`speech.js` の `_flushInterim`）。

## Note（メモ）

```js
{
  id: 'note_...',
  type: 'insight' | 'todo' | 'check' | 'summary' | 'quote',
  text: '見積もりのテンプレを探す',
  color: '#b0463b',         // 種別の色（和の中間色）
  atMs: 8000,               // 記録した時点の経過ミリ秒
  segmentId: 'seg_...' | null,  // 紐づく発言
  createdAt: '...',
  updatedAt: '...'
}
```

メモは `atMs` と `segmentId` の両方を持ちます。
`segmentId` があればその発言へ、なければ `atMs` 以前で最も近い発言（`segmentAt()`）へ戻ります。
音声が保存されていれば、同じ位置から再生も始まります。

## バックアップ形式

```js
{
  app: 'kioku',
  schemaVersion: 1,
  exportedAt: '2026-08-29T11:30:00.000Z',
  sessionCount: 12,
  sessions: [Session, ...]
}
```

- 音声そのものはJSONに含めません（別途「音声」ボタンで書き出します）。
- 取り込み時、IDが既存と重なるセッションは**上書きせず**、別IDのコピーとして追加します。
- `schemaVersion` が現行より新しいバックアップは読み込みを拒否します。

## 保存のタイミング

| 操作 | 保存方式 |
| --- | --- |
| 認識の確定結果が増えたとき | `updateSessionBuffered()`：画面は即時更新、書き込みは0.8秒まとめ書き |
| メモの追加・編集、文の修正 | `updateSession()`：即座に書き込み |
| 一時停止・終了・画面を離れるとき | `flushSaves()` で未書き込み分を確実に書き出す |
